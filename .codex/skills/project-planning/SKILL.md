# Project Planning

Create the plan in the conversation or relevant issue with the user outcome, audience, scope, public/private access decision, data classification, UI approach, test plan, delivery plan, risks, and explicit out-of-scope items. Save a task-specific plan in the repository only when the user explicitly requests that exception. Read the project profile before asking questions. Ask only for fields that are missing or conflict with the requested change.
